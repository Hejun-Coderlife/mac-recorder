录屏 v1.6.1

**这一版修的（Windows）**
- 平时用系统截图截不到录屏的窗口：现在只在录的时候才不出现在画面里（同 Mac 版）。
- 「检查更新」报 403 Forbidden：同一个网络里电脑多时 GitHub 不让查，现在会换一种方式查，照样能收到新版。

**v1.6 加的**

- **画面效果和 Mac 版一样**：玻璃标签 / 玻璃字幕底（边缘像透镜把后面的画面弯过来）、毛玻璃 / 聚光灯 / 聚焦遮挡、11 种文字标签、5 种箭头（普通 / 双向 / 弧形 / 粗 / 虚线）、6 种点击波纹，预览、导出、GIF 都一样。
- **剪辑窗口里能选样式**：文字标签样式、箭头样式、圈（正圆 / 椭圆）、不透明度、自选颜色、遮挡圆角、点击波纹样子和线粗。
- **文字转配音**：字幕菜单 →「文字转配音…」，把字幕念成配音放到讲解轨上。本机 AI 声音免费（第一次用下载约 360MB 声音模型），也能用火山引擎·豆包、微软 Azure、OpenAI、阿里千问（自己填 key）或 Windows 自带声音。
- **AI 控制**：主窗口「✦ AI 控制」一键接上 Claude、Claude Code、Cursor、VS Code、Codex、Trae 等，一句话让 AI 录屏、剪辑、加标注、导出。
- **导出前检查**：测试用的文字、空字幕、没声音、文件太大、摄像头挡住标注……先列出来，可以「去修改」或「仍要导出」。
- **HEVC 导出**：同画质文件小一半左右（导出设置 →「编码」）。
- **只开一个**：已经开着时再双击图标，会把开着的窗口调到前面，不再多开一个抢快捷键。

**Mac**：这一版的 Mac 安装包稍后补上；现在请先用 [v1.5](https://github.com/Hejun-Coderlife/mac-recorder/releases/tag/v1.5)，补上之后会自动提示更新。

已装旧版的 Windows 会在后台自动下载，退出程序时换上新版。程序没有代码签名：Windows 首次打开点「更多信息 → 仍要运行」。
