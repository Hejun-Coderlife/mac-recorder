# 录屏 · Screen Recorder

<img src="docs/icon.png" width="96" align="right">

一个很小的 Mac 录屏工具：选整个屏幕、某个窗口或框一块区域，连同电脑播放的声音（可选麦克风）一起录成 MP4。

A tiny macOS screen recorder: record a whole screen, a single window or a selected area, together with system audio (and optionally your microphone), straight to MP4. The interface follows your system language (Chinese / English).

## 下载 Download

到 [Releases](../../releases/latest) 下载 `ScreenRecorder.dmg`，打开后把「录屏」拖进「应用程序」。

**要求：** Apple 芯片（M1 及以后）的 Mac，macOS 15 或更新。

**第一次打开会被系统拦下**（这个 App 没有经过苹果公证）：
1. 双击打开，看到提示后点「完成」或「取消」；
2. 打开 系统设置 → 隐私与安全性，往下找到「已阻止打开"录屏"」，点「仍要打开」；
3. 第一次录制时，按提示在 系统设置 → 隐私与安全性 → 屏幕与系统录音 里打开「录屏」，然后退出再重新打开。

> First launch is blocked by Gatekeeper because the app isn't notarized: open it once, then go to System Settings → Privacy & Security and click "Open Anyway". Requires an Apple silicon Mac with macOS 15+.

## Windows 版 Windows

Windows 10 / 11（64 位）可用：在 Releases 下载 `ScreenRecorder.exe`，**只有这一个文件**，放哪都行（比如改名叫「录屏.exe」放进 D:\软件），双击就用，不用安装、不用另装别的。第一次打开会把录制引擎和 ffmpeg 解到 `%LOCALAPPDATA%\录屏`（只解一次）。第一次打开如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

Windows: download the single `ScreenRecorder.exe` from Releases and double-click it — no installer, nothing else to install. On first launch it unpacks its recording engine and ffmpeg to `%LOCALAPPDATA%\录屏` once. If SmartScreen warns, click "More info → Run anyway" (not code-signed).

- 录整个屏幕、单个窗口，或框选一块区域（遮罩上拖八个点调大小，点「录制」直接开录，Esc 取消）
- 同时录电脑声音和麦克风（混成一条音轨），可选是否显示鼠标
- 全局快捷键 **Ctrl+Alt+R** 开始 / 停止；录屏窗口本身不会被录进画面
- **截图**：**Ctrl+Alt+X**（两个快捷键都能在窗口里点一下改；被 QQ 之类占用时右下角会提示），屏幕定格后拖框，松手就进剪贴板，直接 Ctrl+V 粘贴
- 截完 / 录完右下角浮出**缩略图**（跟 Mac 一样）：拖进微信、文件夹、剪辑软件就是发过去；单击打开；悬停不消失，× 不要了。截图没动它就自动存到**桌面**，录好的视频也存在桌面
- **后台静默更新**：开着的时候在后台查新版、悄悄下载好，退出程序时自动换上，下次打开就是新的（底部会说一句「已更新到 vX」）；正在录 / 生成时不动它；想马上用就点底部的「现在重启」
- **开录倒计时**（关 / 3 秒 / 5 秒，屏幕中间大号数字，不会被录进去，Esc 取消）；**录制时隐藏桌面图标**（录完自动恢复，程序意外退出的下次打开也会恢复）
- **Studio 效果 + 剪辑窗口**（跟 Mac 版一样，像 Screen Studio）：打开开关正常录，录完打开剪辑窗口——
  - 上面实时预览，中间播放栏（空格播放 / 暂停，←→ 逐帧），下面时间轴：按点击、打字自动排好的推近段（推近时镜头跟着鼠标走），拖两头改长短、拖中间挪、空白处双击新加、Delete 删掉；选中后调放大倍数、选「跟着鼠标 / 固定位置」（固定位置在预览上点一下设定）；两端黄色「[ ]」掐头去尾；Ctrl+Z / Ctrl+Y 撤销重做；Ctrl+滚轮或触控板捏合缩放时间轴
  - 右边样式：画面比例（原始 / 16:9 / 9:16 / 1:1 / 4:3）、背景（纯色 / 渐变 / Windows 自带壁纸 / 自己的图片，默认白色）、边距圆角阴影、鼠标（大小、顺滑、不动自动隐藏、点击波纹、6 种点击音效）、运动模糊（只在镜头快速移动时有一点拖影）、预设（4 个内置 + 自己存，设为新录制默认）
  - **剪掉中间一段 / 快放**：点「✂ 剪掉」（或在时间轴的剪辑轨上双击）在播放头处放一段红色斜纹块，拖两头盖住不要的部分；选中后可改成「快放」2× / 4× / 8×（蓝色斜纹，旁边写着「4.9 秒 → 1.2 秒」）。预览直接跳过 / 快放，导出时剪掉的删掉、快放的按倍数压短（声音音调不变），推近、点击声跟着对齐；播放栏的时间按成片算
  - **声音**（右边「声音」组）：一键静音录到的声音、音量 0–200%（Mac 录的素材电脑声音和麦克风分开调）、点击声音量；超过 100% 也不会破音（限幅）。预览里听到的就是成片的声音（点击声也在），改了音量或剪辑后一两秒生效
  - **录讲解**：播放栏「🎙 录讲解」，默认先倒数 3 秒，然后从播放头开始边放边录麦克风；再点一次、空格或 Esc 停（录的时候按钮变红，显示时长和音量）。录好的在时间轴「讲解」轨（绿色块带波形）：拖中间挪、拖两头剪掉开头结尾，选中后调音量、删除，都能撤销；新录的和旧讲解重叠时以新录的为准。「声音」里有讲解总音量、「讲解时自动压低原声音」（约 -12 dB，默认开）、「录讲解前倒数 3 秒」「录讲解时原声音静音」。录音存在素材夹的 `voice/`，规则和 Mac 版一样（讲解跟着它开头那一刻的画面走）。麦克风要在「设置 → 隐私和安全性 → 麦克风」里允许桌面应用使用
  - **字幕**：播放栏「字 字幕」→ 从录到的声音 / 讲解 / 两样都识别，在本机把普通话变成字幕（whisper.cpp，不上传）。**第一次用会下载识别模型（约 148 MB，存 `%LOCALAPPDATA%\录屏\models`，先连 huggingface.co，连不上自动换国内镜像 hf-mirror.com）**，下载和识别都有进度、能取消。按标点和停顿断句，一次只显示一行（每行最多 16–18 字）。时间轴「字幕」轨：双击改字、拖两头改时间、拖中间挪，选中后可在播放头处拆开 / 和下一句合并 / 删除，空白处双击新加；右边「字幕」组调粗细、字号、颜色、描边、阴影、底色条、位置。预览里实时显示，导出（含 GIF）烧进画面，也能「导出 .srt」
  - **降噪**（「声音」组：关 / 轻 / 中 / 强）：去掉风扇、电流、空调这类持续的杂音，作用在录到的声音（Windows 录的电脑声音和麦克风是一条，一起处理）和讲解上；用 ffmpeg 自带的 afftdn，按这段声音自己的底噪调，预览和导出一样
  - **显示快捷键**（样式「快捷键」组）：录的时候记下按的组合键（只记带 Ctrl / Alt / Win 的组合和 Esc、Tab、回车、退格、Delete、方向键、F 键这类功能键，**普通打字一律不记**），成片画面上浮出键帽「Ctrl + Shift + C」，约 1.2 秒后淡出；位置左下 / 底部居中 / 右下，大小、深色 / 浅色可调，居中时自动让开字幕；剪掉的那段里按的不显示
  - **摄像头画中画**：主窗口勾「摄像头」（接了几个摄像头可以选），屏幕上浮一个能拖的圆形小窗（右键换圆形 / 圆角方形、大小）。普通录制小窗直接录进画面（**只录某个窗口时录不到小窗**，要录整屏或框选区域）；开着 Studio 效果录，小窗不录进原始画面，摄像头单独录成 `camera.mp4`（和屏幕按同一时钟对齐），剪辑窗口里再调：样式「摄像头」组（显示、圆形 / 圆角方形、大小、四个角、边框和颜色、阴影、镜像），在预览上按住小窗直接拖；时间轴「布局」轨双击加一段，换成左右分屏 / 分屏（人像在左）/ 摄像头全屏 / 隐藏，切换时 0.4 秒平滑形变；推近时人像不跟着放大，剪掉 / 快放时摄像头同步。摄像头用随包的 ffmpeg（DirectShow）打开，要在「设置 → 隐私和安全性 → 相机」里允许桌面应用使用
  - **遮挡和标注**：播放栏「✎ 标注」菜单——「遮挡」在预览上拖出一块，选模糊 / 马赛克 / 色块（强度可调，色块可换颜色），遮住手机号、聊天这类隐私；下面是箭头、框、圈、高亮、文字（微软雅黑粗体，可带底色胶囊），颜色、线宽、字号可调，出现消失淡入淡出，箭头像笔画出来。都画在原画面上，推近时跟着一起放大挪动（显卡、CPU 两条合成路径一样）。选中后在预览上拖中间挪、拖 8 个点改大小（箭头拖两头），双击文字改字；时间轴「遮挡」「标注」两条轨（标注叠在一起时最多分 3 行）上拖动改出现的时间，Ctrl+D 复制、Delete 删，都能撤销
  - **背景音乐**：右边「声音」→「♪ 选择音乐…」（mp3 / m4a / wav / aac / flac…，拷进素材夹 `music/`），出现在时间轴最下面的「音乐」轨（带波形）：拖中间挪、拖两头剪掉开头结尾、Delete 删。可调音量、淡入淡出、「循环到片尾」（重复的部分画成淡色块）、「说话时自动压低音乐」（有讲解、或录到的声音里有人说话时压低，默认 -14 dB，可调）。音乐按**成片时间**铺，不跟着剪掉 / 快放变速；预览听到的就是导出的（软限幅不爆音）
  - **推近速度**：右边「推近」选 慢 / 标准 / 快；选中某段推近，属性条里还能单独给这一段设速度（影响到这段结束后 2 秒）
  - **结尾鼠标回到起点**：「鼠标」里勾上后，最后 0.5–2 秒鼠标缓缓走回第一帧的位置（可选镜头同时拉回全景），首尾接得上，适合做循环视频
  - **建议加速**：播放栏右边 ⏩——找出很久没操作、画面也不动的空档（建议 4×）和一直在打字的地方（建议 2×），在剪辑轨上画成虚线块；点 ✓ 采纳（变成正式的快放段，能撤销）/ ✕ 忽略，或在上方条里「全部采纳 / 全部忽略」；建议本身不存进工程
  - **录制时勿扰**（主窗口）：录的时候临时关掉系统通知横幅，录完换回来（程序中途崩了，下次打开也会换回来）。Windows 没有给普通程序开关「专注 / 勿扰」的公开接口，这里改的是通知横幅总开关；Windows 11 的「勿扰」开关本身不动，想更彻底可以自己打开
  - 改动自动存进素材文件夹的 project.json（格式和 Mac 版一样，同一份素材两边都能打开，摄像头布局、快捷键样式、遮挡标注、背景音乐、推近速度、鼠标回到起点两边通用；不认识的字段原样留着，不会丢）
  - **导出**：右上角「导出」旁边的设置按钮（写着「1440p · 60 帧」）选分辨率（原始 / 4K / 1440p / 1080p / 720p，默认 1440p）、帧率 60 / 30、画质（高 / 标准 / 小文件）、视频（mp4）或 GIF（宽 960、每秒 15 帧、没有声音）、「导出后复制到剪贴板」（导完直接去微信粘贴），选了会记住；导出中可以点「取消」，写了一半的文件会删掉。成片在桌面
  - 主窗口下方列出**最近的 Studio 素材**（缩略图、时长、日期，最多 8 个），单击就进剪辑窗口，右键「在资源管理器中显示 / 移到回收站」；也可以把素材文件夹拖到主窗口或 录屏.exe 上打开；「打开 Studio 素材…」照样能用
  - 导出优先用显卡：合成在显卡上画，编码用显卡编码器（NVIDIA / Intel / AMD / Windows 自带，自动挑能用的）；没有显卡时用 CPU，会慢不少。做完显示用时和用的显卡还是 CPU，详细记录在素材文件夹的 render.log。Windows 版没有透明背景（出普通 mp4）
- 程序里带了 ffmpeg（Studio 效果读写视频用），所以 exe 有几十 MB

> **Windows:** run the single `ScreenRecorder.exe` (Windows 10/11 x64; no extra runtime needed). Records a screen, a window or a selected area with system audio and/or microphone mixed into one track; **Ctrl+Alt+R** starts / stops; **Ctrl+Alt+X** takes a screenshot straight to the clipboard (both shortcuts can be changed in the window; you get a notification if another app already uses one). A Mac-style floating thumbnail appears after each screenshot / recording (drag it into any app, click to open, × to discard); screenshots you leave alone and all recordings are saved to the Desktop. Updates itself silently in the background (downloads the new version and swaps it in when you quit; "Restart Now" applies it immediately). Optional countdown before recording and hiding desktop icons while recording. **Studio effects** with the same editor as the Mac version: after recording, an editor opens with a live preview, a timeline of auto-generated zooms (drag to resize / move, double-click to add, follow-cursor or fixed position, trim with the yellow brackets, undo / redo, Ctrl+scroll or pinch to zoom the timeline) and a style panel (aspect ratio, solid / gradient / wallpaper / image background, padding, corners, shadow, cursor size / smoothing / hide when idle / ripple / 6 click sounds, motion blur, presets). Projects are saved as project.json in the footage folder, compatible with the Mac version; Cuts and speed-ups (2× / 4× / 8×) on a cut lane, skipped / fast-forwarded in the preview and removed / compressed in the export with zooms and click sounds kept in sync; a Sound section with mute, volume up to 200% (limited, no clipping) and click volume — the preview plays exactly the exported mix. Export settings: resolution (original / 4K / 1440p / 1080p / 720p, default 1440p), 60 / 30 fps, quality, mp4 or GIF, copy to clipboard after export; exports can be cancelled. The main window lists recent Studio footage (click to edit; drop a footage folder on the window or the exe to open it). **Voice-over**: record narration from the playhead (3 s countdown, Space / Esc to stop) onto a voice lane with waveforms; trim, move, volume, newest take wins; the original is lowered ~12 dB under it. **Captions**: Mandarin speech → one-line captions on this PC with whisper.cpp (the ~148 MB model downloads on first use from huggingface.co, falling back to hf-mirror.com); edit / split / merge / move on the caption lane, style them, burn into the export or save .srt. **Noise reduction** (off / light / medium / strong, ffmpeg afftdn tuned to the clip's own noise floor). **Shortcut keycaps**: only Ctrl / Alt / Win combos and keys like Esc, Tab, Enter, arrows and F-keys are recorded (never normal typing) and shown as “Ctrl + Shift + C” keycaps for ~1.2 s, bottom-left / centre / right, size and dark / light adjustable. **Camera picture-in-picture**: tick “Camera” for a draggable round bubble (right-click for shape / size); normal recordings capture the bubble (not when recording a single window), Studio recordings record the camera separately to camera.mp4 so the editor can style it (shape, size, corners or drag in the preview, border, shadow, mirror) and switch layouts on the Layout lane (side by side, camera left, full, hidden, 0.4 s morph); zooms don't enlarge it and cuts keep it in sync. **Redact & annotate** (“Annotate” in the play bar): blur / mosaic / solid redactions and arrow (draws itself on), box, circle, highlight and text (Microsoft YaHei, optional pill) annotations, dragged out on the preview with 8 handles, fades, Redact / Annotate lanes (up to 3 rows), Ctrl+D duplicate, double-click to edit text; drawn onto the screen footage so zooms carry them, on both the GPU and CPU paths. **Background music** (Sound → Choose Music…, copied into `music/`): a Music lane with waveforms (move, trim, lighter loop repeats), volume, fades, loop to the end, ducking under voice-over and speech (-14 dB by default), laid out in output time, same in preview and export with a soft limiter. **Zoom speed** (slow / normal / fast, per-zoom override), **return cursor to start** at the end (0.5–2 s, optional zoom-out) and **suggested speed-ups** (idle 4× / typing 2× as dashed blocks on the cut lane; ✓ / ✕, Accept All / Ignore All, undoable). **Do not disturb while recording** turns notification banners off and restores them afterwards (also after a crash); the Windows 11 Do Not Disturb switch itself isn't touched. Project fields are shared with the Mac version, and unknown ones are preserved when Windows saves. Export writes to the Desktop (no transparent background on Windows). Rendering uses the GPU when there is one (Direct3D 11 compositing + NVENC / Quick Sync / AMF / Media Foundation hardware encoding, picked automatically), falling back to the CPU; the status bar shows how long it took and render.log in the footage folder has the details. The exe bundles ffmpeg for Studio rendering, hence a few dozen MB. If SmartScreen warns on first launch, click "More info → Run anyway".

## 功能 Features

- 录整个屏幕、单个窗口，或者像系统截图（⌘⇧5）那样框选一块区域，拖八个点调大小
- 同时录电脑声音和麦克风（各一条音轨），可选是否显示鼠标
- 全局快捷键 **⌥⌘R** 开始 / 停止（游戏全屏、点不到按钮时也能用）
- 按屏幕原始像素录制，不缩放；颜色和苹果自带录屏一致
- 文件保存在「影片 / 录屏」
- **开录倒计时**：关 / 3 秒 / 5 秒，屏幕中间出大号数字（不会被录进去），倒计时中按 Esc 或再按一次快捷键取消
- **隐藏桌面图标**：录整个屏幕或区域时，画面里不出现桌面上的图标（只是不录那一层，桌面本身不动）
- **Studio 效果**（像 Screen Studio）：打开开关后正常录就行，录完打开**剪辑窗口**——点击、打字的地方已经自动排好推近段，推近时镜头跟着鼠标走，鼠标更顺滑、点击有波纹，背景透明（存成带透明通道的 .mov，放进剪辑软件可以叠在任意画面上），带圆角和阴影。原始素材留在「影片 / 录屏 / Studio 素材」
  - 时间轴上紫色块是推近段：拖两头改长短、拖中间挪位置，空白处双击（或点「推近」）在那里加一段，选中后按 Delete 删
  - 选中一段可以调放大倍数（1.2–4 倍），选「跟着鼠标」或「固定位置」（点「选位置」后在预览上点一下）
  - 两头的黄色竖条是修剪：拖进来就剪掉开头 / 结尾
  - 剪掉中间一段 / 快放：点「剪掉」在播放头处放一段红色斜纹块，拖两头盖住不要的部分；选中后可改成「加速」2× / 4× / 8×（蓝色斜纹）。预览直接跳过 / 快放，导出时剪掉的删掉、快放的按倍数压短，推近、点击声跟着对齐（工程文件里的 `cuts`；Windows 版也有，两边通用）
  - 录讲解：点「录讲解」（麦克风），默认先倒数 3 秒，然后从播放头开始边播边录你的讲解；再点一次、空格或 Esc 停。录好的讲解在时间轴最下面一条（带波形）：拖中间挪位置、拖两头剪掉开头结尾，选中后调音量、Delete 删，都能撤销。新录的和旧讲解重叠时，重叠部分以新录的为准。「声音」里有讲解总音量、「讲解时自动压低原声音」（约 -12 dB，默认开）、「录讲解前倒数 3 秒」「录讲解时原声音静音」（只影响录的时候，免得被麦克风录进去）。录音存在素材夹的 `voice/` 里（工程文件里的 `voiceovers`；Windows 版也有，两边通用）
  - 字幕：点「字幕」选识别哪段声音（录到的声音 / 讲解 / 两样都要），在本机识别普通话（macOS 26 用系统的 SpeechAnalyzer，第一次会下载识别资源；老系统用本机的 SFSpeechRecognizer），按标点和停顿断句，**一次只显示一行**（每行最多 16–18 字，按画面宽度自动定）。字幕在时间轴最下面一条：双击改字、拖两头改时间、拖中间挪、选中后可在播放头处拆开 / 和下一句合并 / 删除，空白处双击新加，都能撤销。样式在「字幕」分组：粗细、字号、颜色、描边、阴影、底色条、底部 / 顶部和离边距离；竖屏时字自动大一号，放底部时让开抖音等 App 底部的按钮。预览里实时显示，导出（含 GIF）烧进画面，也能「存 .srt」（成片时间）。字幕时间存的是素材时间：之后加剪掉、快放，字幕跟着它那段画面走，整句被剪掉的不出（工程文件里的 `captions`、`captionStyle`；Windows 版也有，两边通用）
  - 降噪：「声音」里选关 / 轻 / 中 / 强，处理麦克风和讲解（电脑声音默认不动，可勾「电脑声音也降噪」）。用的是 macOS 自带的「声音隔离」，在本机处理；第一次选时算一遍（10 秒声音约 0.2 秒），之后换强度不用重算，缓存在素材夹 `denoise/`。预览和导出一致（工程文件里 `audio.denoise`）
  - 摄像头画中画：主窗口勾「摄像头」，屏幕上浮一个能拖动的小窗（右键换圆形 / 圆角方形、大小；接了多个摄像头可以选）。普通录制直接把小窗录进画面；开了 Studio 效果，小窗不录进原始画面，摄像头单独录成 `camera.mp4`（和屏幕画面按同一时钟对齐），剪辑窗口里再调：样式「摄像头」组（显示、形状、大小、在预览上直接拖位置或点四个角、边框和颜色、阴影、镜像），时间轴最下面的「布局」轨双击加一段，换成左右分屏 / 分屏（人像在左）/ 摄像头全屏 / 隐藏，切换时 0.4 秒平滑形变；推近时人像不跟着放大；剪掉 / 快放时摄像头画面同步。工程文件里 `camera` / `layouts`（Windows 版也有，两边通用）
  - 显示快捷键：「快捷键」分组打开后，画面上浮出 ⌘ ⇧ C 这样的键帽，约 1.2 秒淡出；位置左下 / 居中 / 右下、大小、深浅可调。**只记带 ⌘⌃⌥ 的组合和 Esc、Tab、回车、方向键、F 键，打的字一律不记**。给录屏开「系统设置 → 隐私与安全性 → 输入监控」会记得最全；没开时每秒查 120 次按键状态，极快的按键可能漏（轨迹文件里的 `shortcuts`）
  - 遮挡和标注：播放栏「标注」菜单——第一项「遮挡」在预览上拖出一块，选模糊 / 马赛克 / 色块（强度、圆角可调），遮住手机号、聊天这类隐私；下面是箭头、框、圈、高亮、文字（苹方，可带底色胶囊），颜色、线宽、字号可调，出现消失淡入淡出，箭头像笔画出来。都画在原画面上，推近时跟着一起放大挪动。选中后在预览上拖中间挪、拖 8 个点改大小（箭头拖两头），双击文字改字；时间轴「遮挡」「标注」两条轨上拖动改出现的时间，⌘D 复制、Delete 删，都能撤销。工程文件里 `redactions` / `annotations`（Windows 版也有，两边通用）
  - 背景音乐：右边「背景音乐」点「选择音乐…」（mp3 / m4a / wav / aac，会拷进素材夹 `music/`，原文件挪走也不怕），出现在时间轴最下面的「音乐」轨：拖中间挪、拖两头剪掉开头结尾、Delete 删。可调音量、淡入淡出、「循环到片尾」（最后一首放完从头再来，淡色块画出重复的部分）、「说话时自动压低音乐」（有讲解、或录到的声音里有人说话时压低，默认 -14 dB，可调）。音乐按**成片时间**铺，不跟着剪掉 / 快放变速；预览听得到，导出一样（软限幅不爆音）。工程文件里 `music`（Windows 版也有，两边通用）
  - 推近速度：右边「推近」选 慢 / 标准 / 快，控制镜头推近、拉远、跟着鼠标走的快慢；选中某段推近，属性条里还能单独给这一段设速度
  - 结尾鼠标回到起点：「鼠标」里勾上后，最后 0.5–2 秒鼠标缓缓走回第一帧的位置（可选镜头同时拉回全景），首尾接得上，适合做循环视频
  - 建议加速：播放栏右边仪表图标——找出很久没操作、画面也不动的空档（建议 4×）和一直在打字的地方（建议 2×），在剪辑轨上画成虚线块；块上点 ✓ 采纳（变成正式的快放段，能撤销）/ ✕ 忽略，或在上方条里「全部采纳 / 全部忽略」
  - 主窗口下方列出最近 8 份 Studio 素材（缩略图、时长），点一下打开剪辑，右键「在访达中显示 / 移到废纸篓」；把素材文件夹拖到主窗口或程序坞的录屏图标上也能打开
  - 录制时开启勿扰：macOS 不让普通程序直接开关专注模式，所以借两个快捷指令。第一次勾选时点「设置…」，在弹出的「快捷指令」里点两次「添加快捷指令」（「录屏·开启勿扰」「录屏·关闭勿扰」）；之后开录自动开勿扰、录完关掉，程序中途退出的话下次打开时补关
    - 讲解和剪辑的关系：讲解「挂在它开头那一刻的画面上」——之后在它前面加 / 改剪掉、快放，讲解跟着那一刻的画面一起挪；讲解中间那段画面再被剪掉或快放，讲解本身不剪、不变速，照样按真实时间连着放完（录的时候本来就是看着剪过的预览说的）
  - 「声音」里调录到的电脑声音 / 麦克风各自的音量（0–200%，太响自动压住不爆音）、一键静音、点击声音量；预览和导出一样
  - 空格播放 / 暂停，← → 逐帧，⌘Z / ⌘⇧Z 撤销重做；改动自动保存，点「导出」出成片（可以反复导出）
  - 「导出」左边的设置：分辨率（原始 / 4K / 1440p / 1080p / 720p，默认 1440p）、帧率（60 / 30）、画质（高 / 标准 / 小文件）、格式（视频 / GIF），以及导出后复制到剪贴板（直接粘贴进微信、访达）。分辨率越小越快：同一段 35 秒的 Retina 录屏，原始大小约 26 秒、1440p 约 12 秒、1080p 约 7 秒、1080p 30 帧约 4 秒。导出中可以取消
  - 以前录的素材：主窗口「打开 Studio 素材…」选那个文件夹，接着改
  - 右边「样式」面板：
    - **画面比例**：原始 / 16:9 / 9:16（抖音竖屏）/ 1:1 / 4:3
    - **背景**：透明 / 纯色 / 渐变（6 套配色，也能自己挑两色和角度）/ 系统壁纸 / 自己的图片；边距、圆角、阴影深浅和虚化。透明背景导出 .mov，其他背景导出普通 .mp4
    - **鼠标**：大小（0.5–3 倍）、顺滑程度（可关）、不动几秒后自动隐藏、点击波纹、点击音效（导出时每次点击加一声轻响）
    - **运动模糊**：关 / 轻 / 中 / 强。只在镜头快速推拉、移动的那几帧沿方向轻微拖影，镜头停着时一点不糊
    - **预设**：把整套样式存起来、下拉切换；「设为默认」后新录的素材都用它（存在「~/资源库/Application Support/com.hejun.screenrecorder/presets.json」）

  **Studio effects** (Screen Studio–style): record as usual, then a **Studio editor** opens with zooms already placed on clicks and typing (the camera follows the cursor while zoomed). On the timeline, drag a zoom's ends to resize, drag its middle to move, double-click empty space to add one, Delete to remove; set scale (1.2–4×) and Follow cursor / Fixed position (click the preview to set it). Yellow bars trim the start / end. “Cut” marks a part to remove (red stripes) or, once selected, to speed up 2× / 4× / 8× (blue stripes); the preview skips / fast-forwards it and the export removes / compresses it with zooms and click sounds kept in sync (stored as `cuts` in project.json — the Windows version has them too). The Sound section sets computer-audio / microphone volume (0–200%, with a soft limiter), mute, and click volume, in both preview and export. **Voiceover**: click “Voiceover” (mic) to narrate while the video plays from the playhead (optional 3 s countdown; click again, Space or Esc to stop). Takes land on the bottom lane with a waveform — drag to move, drag the ends to trim, set volume, Delete; a new take replaces any overlapping part of older ones. Sound adds voiceover volume, “Lower recorded sound under voiceover” (about -12 dB, on by default) and “Mute recorded sound while recording”. A take is anchored to the frame where it starts: cuts / speed-ups added before it move it along with that frame, while cutting or speeding up footage underneath it doesn't cut or speed up the narration — it keeps playing in real time. Takes are stored in `voice/` as `voiceovers` in project.json (shared with the Windows version). **Captions**: click “Captions”, choose the source (recorded sound / voiceover / both) and Mandarin is transcribed on-device (SpeechAnalyzer on macOS 26, which downloads its model on first use; on-device SFSpeechRecognizer otherwise). Lines break at punctuation and pauses and show **one line at a time** (16–18 characters, by canvas width). On the caption lane: double-click to edit, drag ends / middle, split at the playhead, merge with the next, delete, double-click empty space to add — all undoable. The Captions style section sets weight, size, color, outline, shadow, background bar, top / bottom and margin (bigger and kept clear of app buttons in 9:16). Shown live in the preview, burned into exports (including GIF), and “Save .srt” writes output-time subtitles. Times are stored in footage time, so later cuts / speed-ups carry them along; fully cut lines are dropped (`captions` / `captionStyle` in project.json — shared with the Windows version). Space plays, ← → steps a frame, ⌘Z / ⌘⇧Z undo / redo. Edits save automatically. The **Style** panel sets the aspect ratio (original / 16:9 / 9:16 / 1:1 / 4:3), background (none, color, gradient, macOS wallpaper or your own image) with padding, corner radius and shadow, cursor size / smoothing / hide-when-idle / click ripple / click sound, and shutter-style motion blur (only on fast camera moves, so text stays sharp when still); styles can be saved as presets and one set as the default for new recordings. Export writes a transparent HEVC-with-alpha .mov, or an H.264 .mp4 for any other background. Export settings next to the button: resolution (original / 4K / 1440p / 1080p / 720p, default 1440p), 30 or 60 fps, quality, video or GIF, and copy-to-clipboard after export; smaller sizes export much faster (a 35 s Retina clip: ~26 s original, ~12 s at 1440p, ~7 s at 1080p). Exports can be cancelled. Reopen old footage with “Open Studio Footage…”. The main window also has a recording countdown (off / 3 / 5 s, Esc cancels) and “Hide desktop icons”. **Noise reduction** (Sound section: off / light / medium / strong) cleans the microphone and voiceover with macOS's built-in Sound Isolation, on-device; computer audio is left alone unless “Also denoise computer sound” is on. Processed audio is cached in `denoise/`, so changing the strength is instant. **Keystrokes**: turn on “Show keystrokes” to overlay macOS-style key caps (⌘ ⇧ C) for ~1.2 s at bottom-left / center / right; only combos with ⌘⌃⌥ and keys like Esc, Tab, Return, arrows and F-keys are recorded — typed text never is (allow Input Monitoring for the most complete capture). The main window lists the 8 most recent Studio recordings (click to edit, right-click to show in Finder or trash); drop a footage folder on the window or the Dock icon to open it. “Do Not Disturb while recording” toggles Focus through two Shortcuts you add once via “Set Up…”, and turns it back off after recording (also on next launch if the app quit mid-recording). **Camera picture-in-picture**: turn on “Camera” in the main window to show a draggable bubble (right-click for circle / rounded square and size; pick a camera if you have several). Normal recordings capture the bubble as is; with Studio effects it stays out of the screen footage and the camera is recorded separately to `camera.mp4` (aligned on the same clock), so in the editor you can set show / shape / size / position (drag it in the preview or pick a corner) / border and color / shadow / mirror, and use the Layout lane at the bottom of the timeline (double-click to add) to switch to side-by-side, camera-left, camera full or hidden with a 0.4 s morph. Zooms don't enlarge the camera, and cuts / speed-ups keep it in sync (`camera` / `layouts` in project.json — shared with the Windows version). **Redact & annotate**: the “Annotate” menu in the play bar starts with “Redact” — drag over something in the preview and pick blur / mosaic / solid block (strength and corner radius adjustable) to hide phone numbers, chats and the like; below it are arrow, box, circle, highlight and text (PingFang, optional pill background) with color, line width and size, fade in / out, and arrows that draw themselves on. They're drawn onto the screen footage, so zooms enlarge and move them with the picture. Select one to drag it in the preview (8 handles to resize, arrow ends to re-aim, double-click text to edit); the Redact / Annotate lanes on the timeline set when they show; ⌘D duplicates, Delete removes, all undoable (`redactions` / `annotations` in project.json — shared with the Windows version). **Background music**: in Music, “Choose Music…” (mp3 / m4a / wav / aac, copied into the footage's `music/` folder) puts it on the Music lane at the bottom of the timeline — drag to move, drag the ends to trim, Delete to remove. Set volume, fade in / out, “Loop to the end” (the last song repeats; repeats are drawn as lighter blocks) and “Lower music when someone talks” (ducks under voiceover or speech in the recording, -14 dB by default). Music runs in output time — it isn't cut or sped up with the footage — and sounds the same in preview and export, with a soft limiter (`music` in project.json — shared with the Windows version). **Zoom speed** (Zoom section: slow / normal / fast) sets how fast the camera zooms and follows; a selected zoom can override it. **Return cursor to start** (Cursor section) glides the cursor back to its first-frame position over the last 0.5–2 s, optionally zooming back out, for seamless loops. **Suggest speed-ups** (gauge icon on the right of the play bar) finds long idle stretches (4×) and long typing (2×), shows them as dashed blocks on the cut lane; ✓ applies one as a speed-up (undoable), ✕ ignores it, or use Apply All / Ignore All.

## 自己编译 Build from source

只需要命令行开发工具（`xcode-select --install`），不用 Xcode：

```sh
./build.sh      # 编译并装到 /Applications
./package.sh    # 打安装包 dist/ScreenRecorder.dmg
```
